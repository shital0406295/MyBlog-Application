
# MyBlog Application

## About the Project
MyBlog is a simple and user-friendly Blog Application developed as part of my Codomax Digital Frontend Development Internship.

Users can register, login, create blogs, publish posts and explore blogs.

## Features
- User Registration and Login
- Create and Publish Blogs
- View Published Blogs
- Search Blogs
- Category Filter
- Sort Blogs
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage
